# ADR-008: MVP UI를 Spring Boot 정적 리소스로 제공

## 상태

제안됨

## 맥락

MVP UI는 채널 URL 입력, 로딩 상태, 결과 표시, 오류 표시가 핵심이다. 아직 별도 프론트엔드 앱, 라우팅, 상태관리, 배포 파이프라인이 필요할 만큼 복잡하지 않다.

## 결정

MVP 웹 UI는 Spring Boot의 정적 리소스로 제공한다.

## 검토한 대안

- Spring Boot 정적 HTML/CSS/JavaScript
- 서버 사이드 템플릿
- React 또는 Next.js 별도 프론트엔드

## 결과

### 장점

- 백엔드와 UI를 하나의 애플리케이션으로 배포할 수 있다.
- CORS, 별도 프론트 빌드, 배포 파이프라인 부담을 줄일 수 있다.
- MVP 검증에 필요한 UI를 빠르게 만들 수 있다.

### 단점

- UI가 커지면 구조가 답답해질 수 있다.
- 복잡한 클라이언트 상태관리가 필요해지면 별도 프론트엔드로 분리해야 할 수 있다.

## 구현 시 유의사항

- 정적 파일은 `src/main/resources/static` 아래에 둔다.
- UI는 JSON API를 호출하고, 비즈니스 로직은 서버에 둔다.
- 최소 화면 상태는 Empty, Loading, Success, Error를 지원한다.

## 후속 작업

- MVP 화면의 최소 상태와 문구를 확정한다.
- 결과 복사나 내보내기는 MVP 범위에 포함할지 확인한다.
