# ADR-009: MVP에서는 데이터베이스를 사용하지 않음

## 상태

제안됨

## 맥락

첫 번째 제품 검증 질문은 “채널 URL 하나로 받은 공개 데이터 기반 AI 진단이 유용한가”이다. 분석 이력, 사용자 계정, 워크스페이스, 공유 링크는 이 질문이 검증된 뒤에 판단해도 된다.

## 결정

MVP에서는 데이터베이스를 사용하지 않는다. 각 분석은 요청 단위 연산으로 처리한다.

## 검토한 대안

- 데이터베이스 없음
- 분석 이력용 임베디드 DB
- 처음부터 PostgreSQL 사용

## 결과

### 장점

- 구현 범위가 줄어든다.
- Repository 계층 없이 외부 API와 분석 흐름 검증에 집중할 수 있다.
- 배포와 로컬 실행이 단순해진다.

### 단점

- 새로고침 후 이전 분석 결과를 서버에서 다시 볼 수 없다.
- 분석 이력, 공유 링크, 팀 기능을 바로 제공할 수 없다.

## 구현 시 유의사항

- MVP에서는 Repository 계층을 만들지 않는다.
- 저장 기능이 필요해지면 domain port를 먼저 정의하고 infrastructure adapter로 구현한다.
- 테스트는 저장소 없이 use case와 port fake를 중심으로 작성한다.

## 후속 작업

- 어떤 사용자 행동이 저장 기능 추가의 근거가 되는지 정한다.
- MVP 디버깅에는 기본 로그만으로 충분한지 확인한다.
