# UI 디자인 가이드

## 디자인 원칙
1. 분석 도구처럼 보여야 한다. 마케팅 랜딩 페이지처럼 과장하지 않는다.
2. 사용자는 URL 입력, 로딩 상태, 결과 확인을 빠르게 끝낼 수 있어야 한다.
3. 지표와 AI 인사이트는 분리하되 한 화면에서 비교 가능해야 한다.

## 화면 구조
- 상단: 제품명, 짧은 설명, 채널 URL 입력 폼
- 좌측 또는 상단 패널: 채널 기본 정보와 핵심 지표
- 우측 또는 하단 패널: AI 요약, 강점, 개선 기회, 다음 액션
- 오류 영역: 입력 폼 아래에 명확하게 표시

## 금지 패턴
| 금지 사항 | 이유 |
|-----------|------|
| 장식용 AI 배지 | 기능 가치와 무관함 |
| 보라/인디고 중심 팔레트 | 흔한 AI 템플릿처럼 보임 |
| 과한 그라데이션/글로우 | 분석 도구의 신뢰감을 해침 |
| hero만 있고 기능이 없는 첫 화면 | 사용자는 바로 분석을 시작해야 함 |
| 카드 안의 카드 중첩 | 정보 구조가 흐려짐 |

## 색상 방향
- 배경: 밝은 회색 또는 흰색 기반
- 강조색: YouTube를 연상시키는 절제된 red 계열
- 텍스트: 고대비 neutral 계열
- 오류: red 계열을 사용하되 배경과 텍스트 대비 확보

## 컴포넌트
### 입력 폼
- URL 입력 필드는 첫 화면에서 가장 눈에 띄어야 한다.
- 버튼 텍스트는 짧게 유지한다. 예: `분석`
- 로딩 중에는 버튼 비활성화와 텍스트 변경을 제공한다.

### 지표
- 구독자 수, 조회수, 영상 수는 같은 시각 구조로 표시한다.
- 숫자는 locale formatting을 적용한다.

### 인사이트
- 요약은 한 문단으로 표시한다.
- 강점, 개선 기회, 다음 액션은 목록으로 표시한다.
- 빈 결과 상태를 반드시 제공한다.

## 반응형
- 데스크톱: 채널 정보와 인사이트를 2컬럼으로 배치
- 모바일: 입력 폼, 채널 정보, 인사이트 순서로 1컬럼 배치
